# Issues

**Ein Issue ist ein schlanker Einstiegspunkt in ein Thema.**

**Issues werden an genau zwei Punkten innerhalb einer Session erstellt.**
- Punkt eins, wenn der User mitten in der Session danach fragt.
- Punkt zwei, im Recap am Sessionende.

**Der Titel ist EIN Wort, und er benennt den Gegenstand, nie die Handlung.**
- `Wohnungsmängel`, `Bügeleisen` und `Hausarzt` sind Titel, `Zahnarzt in Frankfurt finden und Kontrolle 2026` ist keiner.

## Issue-Format

```
<Title: ONE word>

Goal:
- <end state>
- <end state>

Area: <area>  (→ process-docs/<area>/, dev/<area>/)
```
